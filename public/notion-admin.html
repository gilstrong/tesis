🧪 Prueba de Sincronización

      

        Envía un registro de prueba a cada base de datos de Notion para verificar que funcionan.
      


      

        
        
        
      


      

        

      

    


    
    

      
⚙️ Variables de Entorno Requeridas

      

        Configura estas variables en el archivo .env en la raíz del proyecto.
      

      
# En el archivo .env del proyecto:

NOTION_TOKEN=secret_xxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxx

NOTION_DB_TESIS_ID=xxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxx
NOTION_DB_GENERAL_ID=xxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxx
NOTION_DB_FACTURAS_ID=xxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxx
      

      

      
    


    
    

      
📖 Guía Rápida de Configuración


      


        

          
1

          

            
Crear la integración en Notion

            
Ve a notion.so/my-integrations → "Nueva integración" → copia el Token de integración.

          

        


        

          
2

          

            
Crear las 3 bases de datos en Notion

            
Crea una página vacía en Notion → agrega una base de datos tipo "Full page database" para cada una: Cotizaciones Tesis, Cotizaciones Generales, Facturas.

          

        


        

          
3

          

            
Agregar columnas a cada base de datos

            

              Tesis: Nombre (Title), ID Cotización (Text), Total (Number), Tomos (Number), Tipo Empastado (Select), Color Tapa (Select), Tamaño Papel (Select), Tipo Papel (Select), Lomo (Checkbox), CD (Number), ITLA (Checkbox), Fecha (Date), Estado Sync (Status), Firebase ID (Text).


              General: Nombre Cliente (Title), ID Cotización (Text), Total (Number), Servicios (Text), Fecha (Date), Estado Sync (Status), Firebase ID (Text).


              Facturas: Razón Social (Title), RNC (Text), NCF (Text), Total (Number), ITBIS (Number), Subtotal (Number), Tipo NCF (Select), Estado (Select), Fecha Facturación (Date), Estado Sync (Status), Firebase ID (Text).
            

          

        


        

          
4

          

            
Compartir cada base de datos con tu integración

            
En cada base de datos → "..." (menú) → "Connections" → busca tu integración y dale acceso.

          

        


        

          
5

          

            
Obtener el Database ID

            

              Abre la base de datos en el navegador. La URL tiene este formato:

              https://www.notion.so/workspace/xxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxx?v=...

              El ID son los 32 caracteres hexadecimales. Cópialo para cada base de datos.
            

          

        


        

          
6

          

            
Configurar el .env y reiniciar el servidor

            
NOTION_TOKEN=secret_xxxx
NOTION_DB_TESIS_ID=xxxx
NOTION_DB_GENERAL_ID=xxxx
NOTION_DB_FACTURAS_ID=xxxx

            
Luego ejecuta: node server.js
